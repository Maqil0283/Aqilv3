# Wedding Invitation V3 - Water Lily Aesthetic

This keeps the V2 vertical scroll experience and functionality while replacing the visual background with an included impressionist water-lily artwork.

## Edit details
Edit `config.js` on GitHub, then commit the change.

## Add photos
Upload `photo-1.jpg`, `photo-2.jpg`, `photo-3.jpg`, and `photo-4.jpg` into `assets/images/`.

## Add music
Upload `wedding-song.mp3` into `assets/music/`.

## Publish
Upload all extracted contents to the root of your GitHub repository. In Settings > Pages, deploy from the `main` branch and `/ (root)`.

## Background
The background is already included at `assets/backgrounds/water-lilies.jpg`. Do not delete or rename it unless you also update `styles.css`.
